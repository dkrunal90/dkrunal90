## Experience through projects

- **AI agent development:** Built hosted conversational agents and tool-enabled workflows with Microsoft Foundry, Python, and the Microsoft Agent Framework.
- **Data platform integrations:** Connected AI applications to Snowflake using MCP, with identity-aware access patterns and auditability.
- **Evaluation engineering:** Created evaluation workflows that combine deterministic scoring with model-based judging, and report results through Azure AI Foundry and Snowflake.
- **RAG and NLP applications:** Developed document question-answering, semantic search, text classification, and named-entity recognition projects.
- **Applied machine learning:** Worked on predictive modeling, deep learning, and computer-vision classification projects using Python and notebooks.
- **Application delivery:** Built API and web-app prototypes, containerized services with Docker, and used cloud deployment and monitoring tools.

An MCP server that connects Azure AI Foundry to Snowflake, with identity mapping,

A framework for evaluating AI agents with deterministic checks for objective

recognition and answer evaluation.
